## Design Context

### Users
The app serves developers and technical operators who create agent harnesses, run multi-step coding sessions, inspect repository changes, and use scoped tools from a native desktop workspace. They need fast navigation between spaces and sessions, durable replayable state, and clear visibility into tool activity without browser overhead.

### Brand Personality
Precise, calm, native. The product should feel like a fast professional instrument: dense enough for repeated work, quiet enough for long sessions, and confident without decorative marketing styling.

### Aesthetic Direction
Use the current `zeronsh/comet` GPUI frontend as the exact visual source of truth: its dark near-neutral surfaces, Geist/Geist Mono typography, translucent hairlines and washes, compact titlebar/header/status rhythm, native macOS glass where supported, restrained indigo accent, and developer-tool density. This is a Rust/GPUI replica, not an Electron or generic web-dashboard aesthetic.

### Design Principles
- Match Comet's current rendered frontend first; preserve DeepSeek Harness behavior underneath it.
- Keep chrome quiet and content dominant; interactive state uses subtle translucent washes rather than heavy borders.
- Prefer native GPUI typography, layout, and motion over web-framework imitation.
- Preserve readable text, visible keyboard focus, and stable dimensions during state changes.
- Every visual port must be compared against the current Comet reference captures before being called exact.
